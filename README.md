# Car Price Prediction

This project aims to predict the selling price of used cars based on features such as brand, model, year, mileage, fuel type, and transmission.

## Dataset
- Source: Kaggle – CarDekho Used Car Dataset
- Columns: Car_Name, Year, Selling_Price, Present_Price, Kms_Driven, Fuel_Type, Seller_Type, Transmission, Owner

## Requirements
- Python 3.8+
- pandas, numpy, matplotlib, seaborn, scikit-learn, jupyter

## Installation
1. Install dependencies:
   pip install -r requirements.txt
2. Open the notebook:
   jupyter notebook Car_Price_Prediction.ipynb
   
## Insights
- Car age and mileage are the most significant predictors.
- Diesel cars tend to retain higher resale value.
- Automatic cars are generally priced higher than manual ones.
